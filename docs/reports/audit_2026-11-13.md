# Audit — 2026-11-13 (public release)

Scope: the repository `quii490/igv-studio` after it was published, plus a functional pass over the app.

## 1. Repository hygiene

| Item | Finding | Action |
|---|---|---|
| Real IGV test data | `fixtures/` contained an unpublished export and session XML (sample names, lab folder paths) | Removed from the public tree and history; `fixtures/README.md` explains how to supply your own. Local copies kept (gitignored). |
| Lab-specific naming | `src/core/labels.ts` hard-coded the lab's `OWT*` prefix mapping | Rules removed; a **track-name mapping box** (persisted in `localStorage`) replaces them. Generic suffix cleanup still applies. |
| Sample tokens in reports/scripts | Validation reports and dev scripts echoed the same names | Sanitised; `docs/validation/` is now generated output and gitignored, curated reports live in `docs/reports/`. |
| Public history | Private history contained the data | Re-created as a single clean commit (`IGV Studio 2.0.0`), force-pushed; release tag moved to it. |
| Presentation | README was a dev log | Rewritten as product documentation; added MIT `LICENSE`, `CHANGELOG.md`, `assets/`, topics, description, homepage. |
| Branches | `electron`, `tauri-poc` on GitHub | Only `main` remains; the private archive repo was renamed `igv-studio-private-archive`. |

## 3. Fixed in this round

1. **Track-name mapping UI was dead code** — `mappingText` state existed but no input was bound to it, so after removing the built-in rules users had no way to map names. Restored a collapsible mapping box with `重新应用映射` and persistence.
2. **Scripts wrote into a missing directory** — after `docs/validation/` became generated output, every test script failed with `ENOENT` when the directory did not exist. All scripts now create it first.
3. **Stale document references** — a screenshot referenced in `docs/DEVELOPMENT.md` no longer exists; removed.
