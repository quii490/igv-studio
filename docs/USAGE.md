# 怎么用（给不写代码的人）

## 为什么双击 `index.html` 是空白

项目根目录的 `index.html` 只是 **Vite 的开发入口**：

```html
<script type="module" src="/src/main.tsx"></script>
```

浏览器打不开 `.tsx`，也不能在 `file://` 下加载这种外部模块，所以双击就是白屏。这不是坏了，是这类项目本来就要么跑开发服务器、要么先打包。

## 桌面 App 版（推荐给导师）

`release/IGV Studio.app`（macOS）或 `release/IGV-Studio-Windows/`（Windows）：

- **双击就是一个独立窗口**，没有地址栏、没有标签页，跟本地软件一样；
- 首次打开 macOS 会拦（未签名）：右键 → 打开；若提示"已损坏"，运行
  `xattr -dr com.apple.quarantine "/Applications/IGV Studio.app"`；
- 需要本机装有 Chrome 或 Edge（macOS 会自动找 Chrome/Edge/Chromium/Brave）。
- 打包后的 app 自带 app.html 与图标，可直接拷贝分发。

重新构建（会复制最新的单文件版进 app）：

```bash
npm run standalone && npm run app   # 产物在 release/，不会被 vite build 清空
```

## 直接双击就能用的版本

用项目根目录（或 `dist/`）里的**单文件版**：

```
IGV-Single-SVG-Studio.html      ← 172 KB，样式和脚本全部内联，无需联网、无需 Node
```

- 双击 → 用 **Chrome 或 Edge** 打开（Safari 未测）。
- 换电脑、发给导师、拷 U 盘都只需要这一个文件。
- 所有处理都在本地浏览器里，SVG 不会上传。

重新生成它：

```bash
npm install
npm run standalone     # 产出 dist/IGV-Single-SVG-Studio.html
```

## 能不能导入 IGV Session XML？

**能导入，但它不能直接变出 SVG。**

| 你给的东西 | 工具能做什么 |
|---|---|
| `.svg`（IGV 导出） | 全部功能：解析、裁剪、改样式、导出 |
| `.xml`（IGV Session） | 读出 genome / locus / 15 条轨道名 / 颜色 / y 轴范围；生成 IGV batch 脚本 |
| **只有 `.xml`** | ❌ 画不出图——session 里只有**数据路径和配置**，没有几何。它记的是 `C:\Users\shuai\…\xxx.bw` 这种路径，浏览器读不到导师机器上的 bigWig |

所以正确的分工是：

```
Session XML ──(生成 batch 脚本)──▶ IGV 渲染 ──snapshot .svg──▶ 本工具排版 ──▶ 论文图
```

### 拖入 XML 后能做什么

1. 左侧会多出 **Session** 面板，显示 `mm10 · 15 轨 · chr14:…`。
2. **「套用轨道名/顺序」**：按 session 顺序把 15 条轨道改名。改名前先在左侧「轨道名映射」里按行填写 `文件名, 显示名`（例如 `example.bw, IgG-rep1`），映射会被记住。
3. **「套用 session 颜色」**：用 session 里的颜色覆盖——**注意这会替换掉 FigureR1 参考配色**，一般不用点。
4. **「生成 IGV batch 脚本」→ 下载 batch.txt**：拿去 IGV 的 `Tools → Run Batch Script` 跑，就会在你指定的 locus 上 `snapshot` 出 SVG。脚本里需要你填两处：`<SESSION_XML>` 的绝对路径、`snapshotDirectory` 输出目录。

## 完整流程

### 第 1 步：在 IGV 里导出 SVG

1. IGV Desktop 载入基因组与 bigWig，调好轨道颜色、顺序、y 轴范围，拖到你想要的区间。
2. `File → Save SVG Image…`，保存成 `chr14_xxx.svg`。
   - 批量：`Tools → Run Batch Script`，脚本里写 `goto chr14:63120461-63147923` + `snapshot out.svg`（`.svg` 扩展名决定矢量导出）。
3. 如果后面想改 y 轴范围，**必须回这一步重导**——本工具不改信号的纵向映射。

### 第 2 步：打开 Studio 并导入

1. 双击 `IGV-Single-SVG-Studio.html`。
2. 把 SVG 拖进左侧虚线框（或点它选文件）。想批量出多个位点时，可以先拖入 session `.xml`，再用里面生成的 batch 脚本让 IGV 一次跑完。
3. 底部状态栏会显示解析结果，例如：

```
已解析：3 条轨道，标定方法 both | 标定 both · 0.0350 px/bp | 双源差 -0.39 px | 源对象 7800 | 输出信号对象 7675
```

- `标定方法 both` = 标尺刻度和 locus 文本两路都识别到了。
- `双源差` 绝对值 > 1 px 时，导出按钮会变灰（不允许拿不可靠坐标出图）。

### 第 3 步：调整（可直接点选/拖动）

顶部三个工具：**选择 / 平移 / 裁剪**（快捷键 S / H / C）。

| 操作 | 效果 |
|---|---|
| 单击文字（轨道名、范围、基因名、chr） | 出现蓝色选框，右侧显示该对象属性 |
| 拖动选中对象 | 自由摆放；一次拖动 = 一条撤销记录 |
| 双击文字 | 就地改文字（`[0 - 316]` 只读，绑定 y 轴） |
| Shift+单击 / 空白拖动 | 多选 / 框选 |
| 方向键（Shift ×5） | 微调 1 pt |
| Delete | 隐藏该对象 |
| 滚轮 | 以鼠标为中心缩放基因组窗口 |
| 平移工具拖动 | 移动基因组窗口（不会超出源 SVG 区间） |
| 裁剪工具拖动 | 拉出新的可见区间 |
| ⌘/Ctrl+Z、⇧⌘/Ctrl+Z | 撤销 / 重做 |

右侧「选中对象」面板可改：文字、字号、对齐、隐藏、归位、复制样式。多选时改字号会应用到全部选中项。

**两套缩放别混淆**：右上「视图」只改显示大小；滚轮改的是真实基因组窗口（ruler 会跟着变，峰高不变）。

### 第 3b 步：参数面板

| 想做的事 | 在哪 |
|---|---|
| 裁掉左右不要的区间 | 左侧「2 · 裁剪」输入起止 bp，或拖预览图上两条蓝色竖手柄 |
| 图太窄/太宽 | 左侧「数据区宽 pt」（参考 101.7） |
| 轨道太高/太挤 | 「轨道节距 pt」（参考 8.12） |
| 字号 | 「4 · 文字」里的轨道名/范围/刻度/基因名/染色体 |
| 描边粗细 | 「5 · 描边」（参考 0.25） |
| 轨道改名、换色、排序、隐藏 | 右侧轨道卡片 |
| 显示/隐藏标签、范围、标尺、基因模型、基线 | 左侧勾选框 |
| 一键套导师那套样式 | 顶部「套用 FigureR1 预设」 |
| 撤销/重做/重置 | 顶部按钮 |

注意：
- 右侧 `ymax` 是**只读**的，值来自源 SVG 的 `[0 - 316]`；改它不会改信号，所以干脆不允许改。
- 裁剪后画布会**变窄**（保证峰高不随裁剪变化）；想要更宽的图，调大「数据区宽 pt」。

### 第 4 步：导出

- 「导出 SVG」→ 得到 `原文件名.edited.svg`：无位图、文字仍是 `<text>`、信号仍是原始 rect/line。
- 「导出配置 JSON」→ 保存这次的样式；下次「导入配置」直接复用。
- 在 Illustrator 里打开导出的 SVG，逐个位点自行拼成最终 Figure（本工具刻意不做多 Panel 拼版）。

## 常见问题

**Q：拖进去没反应 / 状态栏报错？**
A：看底部红色提示。常见是「SVG XML 解析失败」（文件被别的工具改坏）或「拒绝导入：含 ENTITY」（安全策略）。

**Q：导出按钮是灰的？**
A：坐标标定没过。底部会写原因，例如「两套标定在区间起点相差 x px」或「只有单一来源标定」。

**Q：直方图看起来被切顶了？**
A：轨道内容高于节距时会被行裁剪，底部会显示「N 条轨道内容高于节距」。调大「轨道节距 pt」或减少轨道高度需求。

**Q：能一次处理很多个位点吗？**
A：目前是逐个导入/导出，没有队列 ZIP；也明确不做多面板拼版。

**Q：Windows 上能用吗？**
A：能，单文件版用 Chrome/Edge 打开即可，不需要装 Node。
